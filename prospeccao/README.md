# C.A. Prospecção

Aplicação separada para testar o fluxo de prospecção do Cortou Anotou.

Nesta primeira versão:
- busca barbearias por cidade usando dados públicos do OpenStreetMap;
- permite selecionar contatos;
- permite editar a mensagem de abordagem;
- não envia mensagens reais;
- não usa nem altera o banco de produção do Cortou Anotou.
